    How this works
    1. Paste a link. A video page, a direct file, a stream. Tap Paste, or share a link into this app.
    2. Pick a quality, tap Download. Fetching, merging and converting happen on this device. Nothing is uploaded.
    3. Save it. The file lands in your downloads, and the row stays here until you clear it.

    Where downloads come from

    Paste a link and it downloads on this device. Some sites — YouTube above all — refuse a web page, and for those this app needs a helper. Give it one address; it works out what that address is.

    Any of these, and it is recognised on its own: your own siphon server — the server/ folder, one docker run. With ffmpeg it does everything: every site yt-dlp knows, playlists, subtitles, your YouTube cookies. Without ffmpeg it only resolves links and this device downloads and converts. A cobalt instance, for what this device cannot read. An Invidious or Piped instance, for YouTube. A relay — relay/, a free Cloudflare Worker — which adds the missing header and nothing else. Leave it empty and this device still handles direct files, HLS and pages that allow it.

    Find a public instance tries the Invidious instances published beside this app — the list at docs.invidious.io, refreshed daily — then the cobalt, Invidious and Piped projects' own directories, and fills in the first that answers. It is someone else's server: the address it picks is named here and on the main screen, it sees every link it is asked about, and clearing the field undoes it.

    YouTube turns anonymous downloads away with "Sign in to confirm you're not a bot". Your server already retries with several of YouTube's own clients, and that clears most of it. When it does not, your own session does — export cookies.txt with a Netscape-format cookie extension and upload it here.

    This is a logged-in session. Only upload it to a server you control, and use a throwaway account if you would rather not hand over your main one.

    Advanced

    ffmpeg.wasm is deployed beside this app and fetched from there the first time a download needs converting on this device — about 32 MB, cached afterwards. Nothing to set. This is only for pointing at a different build.

    The bridge. A userscript that lets this page fetch anything, with no server anywhere — see bridge/ in the project. Once installed it is used automatically, ahead of any helper.
